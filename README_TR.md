### 👨‍💻 Hakkımda

İstanbul merkezli bir **Full-Stack Geliştirici** ve **Oyun Sistemleri Mimarıyım**. Yazılım mühendisliğini birbirini besleyen iki farklı kulvarda sürdürüyorum: **yüksek ölçekli kurumsal web sistemleri** (İnsan Kaynakları takip, çoklu depo stok yönetimi, otomotiv CRM/MLS) ve **derinlikli oyun simülasyon mimarileri** (durum makineleri, deterministik savaş simülatörleri, saf C# alan mantığı).

Geliştirme felsefemin merkezinde **mimari disiplin** yer alır: Gevşek bağlı (decoupled) iş mantığı, yüksek birim test (unit test) kapsamı ve kesintisiz kullanıcı deneyimi.

- 🚀 **Full-Stack Mühendisliği:** **C# / .NET 8**, **Entity Framework Core**, **React** ve **Next.js** ekosistemiyle güvenilir API'ler ve modern web arayüzleri geliştirme.
- 🎮 **Oyun Sistemleri ve Mimari:** **Redoubt**'un yaratıcısı — **198 birim test** ile doğrulanmış, UnityEngine bağımlılığı olmayan saf C# çekirdek motoru ve web simülasyon ortamına sahip mobil krallık strateji RPG'si.
- 🏢 **Kurumsal Deneyim:** **Personel Takip Sistemi (PTS)**, **Envanter ve Stok Yönetimi** ve **Otomotiv CRM/MLS** gibi canlıda çalışan kritik projelerde uçtan uca geliştirme.
- 🧪 **Mühendislik Standartları:** Clean Architecture, SOLID prensipleri, Domain-Driven Design (DDD), Unit Testing (xUnit/NUnit) ve Python tabanlı otomatik asset işleme hatları.
- 📍 **Durum:** İstanbul merkezli · Yazılım ve oyun mühendisliği projeleri ve iş birliklerine açık.

### 🌟 Öne Çıkan Projeler

<details open>
<summary><b>🏰 Redoubt — Mobil Krallık Stratejisi & Kahraman Toplama RPG</b></summary>
<br/>

> **Unity, C# ve .NET 8 ile geliştirilen yüksek performanslı mobil simülasyon oyunu.**

- **Mimari:** UnityEngine bağımlılığı bulunmayan saf C# etki alanı çekirdeği (`Redoubt.Core`), deterministik savaş ve ilerleme mantığını güvenceye alan **198 birim test**.
- **Kayıt Bütünlüğü:** SaveRoundTrip testleri ile tam tur JSON serileştirme doğruluğu.
- **Web Simülasyonu:** Uzaktan test ve savaş simülasyonları için ASP.NET Core tabanlı web arayüzü (`Redoubt.Web`).
- **Araç Hattı:** Otomatik varlık üretimi, 9-slice optimizasyonu ve mock render için Python betikleri.
- 🔗 **Repo:** [github.com/ercnenesDev/Redoubt](https://github.com/ercnenesDev/Redoubt)
</details>

<br/>

<details>
<summary><b>👥 Personel Takip Sistemi (PTS) & Mobil</b></summary>
<br/>

- **Çoklu Depo Yönetimi:** Depo/şube bazlı personel görevlendirmeleri, vardiya ve devamsızlık takibi.
- **İş Akışı Otomasyonu:** İzin talepleri, masraf yönetim süreçleri ve hiyerarşik yönetici onay adımları.
- **Çok Platformlu:** .NET Core ve Entity Framework Core arka ucu, React web paneli ve eşlik eden mobil istemci.

</details>
