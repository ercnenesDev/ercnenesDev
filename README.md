### 👨‍💻 About Me

I am a **Full-Stack Developer** and **Game Systems Developer** based in Istanbul, Turkey. I design and build reliable, scalable software spanning two dynamic domains: **mission-critical web applications** (enterprise HR, stock inventory, automotive CRM/MLS) and **complex game simulation architectures** (state machines, battle engines, runtime UGUI pipelines).

I approach software engineering with an **architecture-first mindset** — prioritizing clean decoupled domain logic, testability, and deterministic performance over ad-hoc solutions.

- 🚀 **Full-Stack Development:** Building production-grade web systems and REST APIs with **C# / .NET 8**, **Entity Framework Core**, **React**, and **Next.js**.
- 🎮 **Game Systems & Architecture:** Creator of **Redoubt** — an ambitious mobile kingdom strategy & hero collection RPG with a decoupled pure C# engine validated by **198 unit tests**.
- 🏢 **Enterprise Impact:** Hands-on experience developing and deploying enterprise systems, including **Personnel Tracking (PTS)**, **Inventory Stock Systems**, and **Automotive CRM/MLS**.
- 🧪 **Engineering Standards:** Clean Architecture, SOLID principles, Domain-Driven Design (DDD) concepts, Unit Testing (xUnit/NUnit), and automated Python asset pipelines.
- 📍 **Status:** Based in Istanbul · Open to software engineering & game development collaborations.

- **Save Integrity:** Schema-safe capture/apply persistence system with round-trip equality testing.
- **Web Simulation:** Companion ASP.NET Core web platform (`Redoubt.Web`) for remote testing and battle simulation.
- **Pipeline:** Automated Python tooling for asset generation, slice optimization, and UI rendering mockups.
